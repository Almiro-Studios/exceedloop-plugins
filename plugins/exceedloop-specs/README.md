# ExceedLoop Specs

Connects your agent to [ExceedLoop](https://app.exceedloop.ai): plans, solution docs, ADRs, UX docs, tasks, rules and skills, over a remote MCP server with OAuth sign-in.

MCP server: `https://app.exceedloop.ai/api/mcp` (streamable HTTP, OAuth). Registry name: `ai.exceedloop/specs`.
