# ExceedLoop Specs

ExceedLoop Specs connects your coding agent to [ExceedLoop](https://app.exceedloop.ai), a spec-driven delivery workspace for AI agent teams. With the plugin installed, your agent can read and update plans, solution docs, ADRs, UX docs and task lists, tick off tasks as it ships, leave comments, and pull your team's shared rules and skills, so every session starts from the same source of truth.

## What it adds

- The remote MCP server `https://app.exceedloop.ai/api/mcp` (streamable HTTP).
- Sign-in with your ExceedLoop account through OAuth the first time a tool is used. No API keys to paste.

## Setup

1. Install the plugin, or add the MCP server URL above as a custom connector.
2. Run any ExceedLoop tool, for example "show my next steps", and sign in when the browser opens.
3. Pick the organisation and project to work in.

You need an ExceedLoop account. Request access at https://app.exceedloop.ai.
