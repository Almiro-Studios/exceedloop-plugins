# ExceedLoop Sketchpad

ExceedLoop Sketchpad gives your coding agent a real design canvas. The agent can list projects, create pages and sections, build reusable components and place instances of them, apply validated layout changes, render any page or frame to PNG to check its own work, and export the result as code. Designers can file fix requests from the editor, and the agent picks them up from the same queue.

## What it adds

- The remote MCP server `https://sketchpad.exceedloop.ai/mcp` (streamable HTTP).
- Sign-in with your ExceedLoop account through OAuth the first time a tool is used. No API keys to paste.

## Setup

1. Install the plugin, or add the MCP server URL above as a custom connector.
2. Ask your agent something like "list my Sketchpad projects" and sign in when the browser opens.

You need an ExceedLoop account. Learn more at https://sketchpad.exceedloop.ai.
